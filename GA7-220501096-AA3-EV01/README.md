# Aorom Joyería

Módulo web de catálogo para Aorom Joyería, construido con React y Vite. La interfaz se adapta a escritorio y móvil.

## Funcionalidades
- Catálogo demostrativo con nombre, categoría y precio en pesos colombianos.
- Filtro por categoría y búsqueda por nombre o categoría.
- Favoritos interactivos y bolsa con contador durante la sesión.
- Diseño adaptable y sección de identidad de marca.

## Requisitos y ejecución
Se requiere Node.js y npm.

```bash
npm install
npm run dev
```

Para generar la versión lista para publicar: `npm run build`.

## Alcance y supuestos
Es una interfaz funcional con datos de muestra en memoria. No incluye inventario conectado, cuentas de usuario, pagos ni persistencia de la bolsa. Nombres, precios e ilustraciones deben reemplazarse por información aprobada de Aorom Joyería.

No se encontraron los diagramas, historias de usuario ni prototipos previos en la carpeta de trabajo. El alcance propuesto se documenta en `docs/alcance-modulo.md` y debe validarse frente a esos artefactos.
